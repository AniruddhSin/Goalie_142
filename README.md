# Goalie_142

Aniruddh Sindhu
14.2: Make a Build
Unity Version 2021.3.45f2
Made for MacOS
Keyboard controls
Player must manipulate a box via quad directional physics influences to push a ball into a goal that is tended by an AI controlled box that acts as the goalie.
Known Bugs: each wall of the goal counts as a separate goal when the ball collides with them.
